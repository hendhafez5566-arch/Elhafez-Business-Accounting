# قوائم الاختيار المحلية للمتابعة

## المشكلة والسلوك الجديد

كانت الصفحة تستطيع استرجاع الطلب المحفوظ، لكن قوائم اختيار العميل المحتمل والمسؤول تصبح فارغة عند إعادة فتحها أثناء غياب الخادم. أصبح بالإمكان تحميلها من الخادم ثم حفظ نسخة مشفرة منها صراحة بعبارة الحماية المكتوبة في الصفحة، واسترجاعها عند الانقطاع لتجهيز طلبات جديدة بالقائمة المحلية.

الحفظ يضم معرف العميل ورقمه واسمه ومرحلة البيع، ومعرف المسؤول واسمه، ووقت تحميل هذه البيانات من الخادم فقط. لا تُنسخ الهواتف أو الملاحظات أو القيم المالية أو الجلسة أو ردود API كاملة. البيانات تبقى تحت AES-GCM في نفس قاعدة المسودات، بمفتاح مستقل خاص بالمستخدم والشركة والفرع. لا تغيير في إصدار القاعدة أو API أو Prisma أو أصحاب البيانات.

تعرض الصفحة إن كانت القوائم من الخادم أو نسخة محلية، مع تاريخ تحميلها. استرجاع نسخة قديمة لا يجعل تاريخها جديدًا ولا يتيح إعادة حفظها باعتبارها بيانات حديثة. يوجد تحديث صريح من الخادم وحذف مستقل للنسخة المحلية؛ الحذف لا يحذف المسودة أو طلبات الإرسال ولا يدعي محو كل بيانات الشاشة المفتوحة. محاولة استبدال نسخة موجودة بعبارة خاطئة تفشل وتحفظ النسخة الأصلية.

العملاء المنتهية فرصهم وفق النسخة المسترجعة لا يظهرون كخيارات لطلب جديد. قد تتغير المرحلة أو صلاحية المسؤول بعد أخذ النسخة؛ النسخة المحلية ليست مصدر صلاحية ولا قبولًا نهائيًا. كل إرسال يستخدم مسار crm-followups المعتاد وصلاحياته وهويته الثابتة، والرفض يترك الطلب محفوظًا.

## الأدلة

نجحت 9 حالات متصفح جديدة (10 باحتساب الاختبار الأب):

- حفظ مشفر صريح مع خرائط بيانات محدودة ووقت تحميل.
- إعادة فتح الصفحة مع غياب API واسترجاع الخيارات وتاريخها.
- تجهيز طلب جديد محليًا من الخيارات المسترجعة دون أي POST.
- استرجاع النسخة بعد إعادة تشغيل عملية المتصفح.
- عبارة خاطئة لا تكشف الأسماء ولا تستبدل النسخة.
- عزل الشركة والفرع والمستخدم ورفض الجلسة المنتهية.
- تغيير المستخدم أثناء فك التشفير لا ينقل الأسماء إلى المستخدم الجديد.
- رفض الخادم عند إرسال طلب قديم لا يثبت قبوله ولا يحذفه.
- حذف النسخة مع بقاء المسودة والطلب.

أُعيدت أجنحة المتصفح السابقة: قائمة الطلبات 15، الإرسال 13، المسودة 9، الواجهة العامة أوفلاين 8؛ كلها نجحت. الإجمالي 54 حالة، أو 59 مع الاختبارات الآباء. اختبارات الويب 99 نجحت. فحوص الأنواع والبناء وlint والمعمارية ونطاق التغيير مطلوبة كذلك؛ نتيجة GitHub الحالية في PR #146.

## حدود التنفيذ

اختبار المتصفح يستخدم API تجريبيًا ويحقن جلسة صالحة صراحة؛ لا يثبت تسجيل دخول أوفلاين. قبول AppModule والصلاحيات وPostgreSQL منفصل في الأجنحة السابقة. إيقاف API مع استمرار تقديم ملفات الاختبار يثبت سلوك البيانات المحلية، واختبار الواجهة العامة السابق هو دليل فتح ملفات البناء بعد غياب الخادم بالكامل؛ لا ندمج الوصفين في ادعاء اختبار واحد شامل.

لا تخزين تلقائي لكل العملاء، ولا قراءة حسابات محلية، ولا مزامنة تلقائية، ولا صلاحيات جديدة. عبارة الحماية غير قابلة للاسترجاع هنا، ومسح بيانات المتصفح يزيل النسخة. النسخة قابلة للتقادم، وتبقى صلاحية الجلسة شرطًا للعمل المحلي من هذه الشاشة. هذه خطوة لتجهيز المتابعات أثناء الانقطاع وليست إكمال أوفلاين جميع الأقسام أو قبولًا للبيع.
