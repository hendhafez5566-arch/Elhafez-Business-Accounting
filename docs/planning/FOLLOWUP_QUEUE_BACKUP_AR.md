# نسخة طلبات المتابعة المحلية واسترجاعها

## السلوك

يمكن تنزيل ملف JSON مشفر لطلبات المتابعة المحلية ثم اختيار الملف واسترجاعه صراحة في متصفح آخر لنفس المستخدم والشركة والفرع. يحتاج الملف عبارة الحماية الأصلية. الحفظ يشمل بيانات الطلبات وهوياتها والنتائج التي سبق تأكيدها محليًا؛ لا يشمل المسودة أو قوائم الاختيار أو ملفات الواجهة أو بيانات الدخول أو حسابات الشركة. ليس نسخة احتياطية كاملة للنظام ولا وسيلة لاستعادة عبارة مفقودة.

الملف يستخدم AES-GCM مع PBKDF2 وملح وIV عشوائيين، ويربط التشفير بهوية المستخدم والشركة والفرع. بيانات الطلبات نفسها داخل التشفير؛ معرفات النطاق وصيغة الملف وإصداره ظاهرة خارجه. لا يحفظ العبارة أو token. حده ٥ ميجابايت و٥٠٠ طلب في الملف، كحدود للتنسيق وليس دليل أداء مئات الطلبات.

الاسترجاع يراجع الملف ويفك تشفيره قبل الإضافة. يضيف الهويات الناقصة فقط؛ الهوية الموجودة تظل ببياناتها ونتيجتها الحالية دون استبدال. اختلاف بيانات نفس الهوية أو تكرارها داخل الملف يرفض العملية كلها. مقارنة النسخة المحلية داخل معاملة الكتابة تكشف أي تغيير متزامن؛ لا يضيع تأكيد وصل أثناء الاسترجاع. إضافة الطلبات ذرية، فلا يبقى نصف الملف عند فشل الكتابة.

اختيار النموذج الحالي والمسودة وقوائم الاختيار لا تتغير. لا تسجيل دخول ولا POST ولا إعادة إرسال تلقائية أثناء التصدير أو الاسترجاع. التأكيدات المسترجعة تاريخ محفوظ لما سبق تأكيده، وليست استعلامًا عن أحدث حالة للخادم. مرجع الحقيقة النهائي والصلاحيات يظلان مع crm-followups ومسار الإرسال المعتاد.

## الأدلة

نجحت ١١ حالة Chromium جديدة (١٢ مع الأب): تنزيل فعلي من الواجهة، اختيار ملف واسترجاعه في profile آخر، الاحتفاظ بالهويات والنتائج، تكرار الاسترجاع دون إضافات، حماية التأكيد الأحدث، العبارة الخاطئة وتعديل التشفير وعزل النطاق، تعارض وتكرار الهويات والنتائج غير الصالحة، صيغة/إصدار/حجم غير مدعوم، إلغاء معاملة بعد بدء الإضافات دون أجزاء محفوظة، تأكيد يتسابق مع الاسترجاع، استقلال النموذج والمسودة والمراجع، الاسترجاع المتزامن وإعادة تشغيل المتصفح. بعض البنود مجمعة داخل الحالة نفسها.

اختبار المتصفح يستخدم FollowupsPage وIndexedDB وWebCrypto الفعليين مع API تجريبي وجلسة صريحة؛ ليس دليل دخول أوفلاين أو قبول من Nest/PostgreSQL. أجنحة القبول السابقة توثق هذه الحدود بصورة منفصلة. نتيجة GitHub الحالية في PR #146. لا دمج أو نشر ضمن العمل.

## المتبقي

التشغيل الكامل أوفلاين، تفويض محلي قابل للانتهاء، مزامنة تلقائية، تسوية الرفض النهائي، واستعادة المفاتيح ليست منفذة بهذا الملف. يجب حفظ الملف خارج بيانات المتصفح إذا كان الغرض استرجاعه بعد مسحها. لا يحمل الملف صلاحية الاطلاع على مستخدم أو فرع مختلف.
