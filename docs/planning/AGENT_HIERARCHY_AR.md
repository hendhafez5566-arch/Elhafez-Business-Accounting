# علاقة المندوب الرئيسي والتابعين

## التنفيذ

أصبح المندوب في agent-management مستقلًا أو مرتبطًا بمندوب رئيسي من نفس الشركة. يمكن تغيير الرئيسي أو فصل العلاقة عبر أمر مستقل بصلاحية crm.agent.manage. مسار HTTP الجديد هو POST /crm/agents/:id/parent مع parentAgentId أو null. الحقل الجديد parentAgentId اختياري في العقد العام حفاظًا على التوافق، والمخزن يعيد null للسجلات القديمة.

شاشة المندوبين تعرض العلاقة وعدد التابعين المباشرين، مع اختيار المندوب والرئيسي والحفظ أو الفصل والتحديث. القوائم مستقلة عن فلاتر قائمة المندوبين الرئيسية حتى لا يخفي البحث أحد الآباء. تعليق الرئيسي لاحقًا لا يمحو التابعين، لكنه لا يسمح بإضافة تابع جديد له. يمكن فصل علاقة موجودة أو نقلها إلى رئيسي نشط.

التحقق يمنع الذات والدوائر المباشرة والمتعددة والمندوب الموجود في شركة أخرى. كتابة علاقة PostgreSQL تقفل تعديلات الشجرة للشركة داخل نفس المعاملة ثم تفحص المسار وتكتب التغيير. تعديل الملف العادي لا يكتب حقل الأب، فيحافظ على علاقة أحدث حتى لو بدأ من قراءة قديمة. الربط مركب بالشركة، ومفتاح أجنبي يمنع حذف رئيسي له تابعون. توجد كذلك حماية قاعدة بيانات من ربط الذات. المنع الكامل للدوائر يعتمد على مسار المالك المسلسل؛ لا ترخيص لكتابة SQL خارج المالك.

المهاجرة 20261015160000_agent_hierarchy تضيف عمودًا nullable وفهرسًا وعلاقة ذاتية وcheck إلى am_agents فقط، ولا تعيد كتابة مهاجرات قديمة ولا تضيف مالكًا موازيًا. توثيق قبل/بعد التغيير يمر عبر تدقيق platform-core المعتاد، خارج معاملة الشجرة مثل عمليات المندوب الحالية؛ لا ندّعي سجل تاريخ مالي أو ذرية مشتركة مع التدقيق.

## الأدلة وحدودها

نجحت محليًا 11 اختبارًا للوحدة (الأربعة السابقة وسبعة جديدة)، و5 حالات متصفح (6 مع الأب) على المكون الفعلي مع HTTP fixture، واختبارات الويب 99، وفحوص أنواع المندوبين والويب وAPI وlint والبناء والمعمارية.

أُضيف قبول PostgreSQL صريح من 5 حالات: الحفظ وتغيير الرئيسي والفصل، نطاق المفتاح الأجنبي وحماية الحذف، سباق اتصالين يحاولان تكوين دائرة، الدائرة غير المباشرة والرئيسي المعلق، وحفظ العمولة الدقيقة والعلاقة خلال تعديل الملف. يُنفّذ في قاعدة CI المؤقتة القائمة مع كامل المهاجرات. كما أُضيفت حالتا HTTP في AppModule الحقيقي للتحقق من المسار والحفظ والدائرة والنطاق والمدخل الناقص ومنع دور لا يملك صلاحية المندوبين. نتيجة التنفيذ الحالي مرجعها فحص PR #146؛ اختبارات القاعدة لم تُنفّذ محليًا في هذه البيئة.

هذا إنجاز للعلاقة التنظيمية فقط. لا توزيع عمولة رئيسي/تابع، ولا دمج أو نقل مديونيات، ولا تغيير للمستحقات أو اتفاقات الحجوزات أو ربح الشركة، ولا صلاحيات دخول للمندوب. تفاصيل الاستحقاق والتسوية حسب الحجز باقية ضمن G04 وليست مغلقة بهذا العمل. لا تشغيل أوفلاين لهذا الأمر؛ التنفيذ المعتمد يحتاج الخادم.
