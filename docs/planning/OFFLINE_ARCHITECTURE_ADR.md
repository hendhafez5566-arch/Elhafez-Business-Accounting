# ADR: مرجع الكتابة والمزامنة عند انقطاع الإنترنت

الحالة: **مقترح هندسي يحتاج تجربة — لا تنفيذ إنتاجي ولا قرار نهائي بأداة**.

## الاحتياج

المستخدم يريد النظام كله متاحًا بدون إنترنت، وليس موظفي الميدان فقط. شرط التجربة يشمل عدم فقد المال أو تكراره وعدم تجاوز السعة. لغة/محرك المزامنة يحدده المهندس بعد إثبات مناسبته؛ لا يُطلب من صاحب العمل اختيار قاعدة بيانات.

## نتيجة فحص الوضع الحالي

عميل CRM يستدعي API مباشرة. تطبيقات الويب وAPI موجودة، لكن لا دليل تنفيذ قاعدة محلية أو طابور مزامنة يشغل كل الوظائف المنفصلة. وجود durable idempotency في المخزون والقيود مفيد لإعادة المحاولة، لكنه ليس محرك مزامنة.

## الفصل الضروري

| الحالة | مرجع مقترح | ما يثبت قبل اعتماده |
|---|---|---|
| المكتب متصل بالشبكة الداخلية والإنترنت مقطوع | خادم مكتب محلي يملك كتابة واحدة لحسابات الشركة | دخول وصلاحيات وترقيم وقيد ومرفق وحفظ وإعادة تشغيل بدون استدعاء خارجي إجباري |
| موبايل أو جهاز خارج شبكة المكتب | سجل عمليات محلي مصرح ومقيد بنطاق البيانات | حفظ دائم وطابور واضح وإعادة محاولة مع تفويض منتهي المدة وتشفير وخطة استرجاع |
| أجهزة مستقلة تطلب آخر مكان | حصص سعة محجوزة مسبقًا أو طلب معلق للتأكيد | لا تأكيد نهائي لنفس المكان على جهازين بلا مرجع أو حصة |
| استضافة ومكتب منفصلان يكتبان في نفس الوقت | ملكية كتابة/حصص/بروتوكول نزاع محدد | لا نسخ snapshot كامل فوق الآخر، ولا last-write-wins للمال أو السعة |

لا يمكن الوعد بتأكيد نهائي غير مقيد على كل جهاز منفصل مع ضمان فوري لسعة مشتركة لا يمكنه رؤية استخدامها. يجب أن توضح الواجهة ما هو معتمد محليًا، وما له صلاحية محدودة، وما ينتظر القبول. هذا تحديد هندسي لازم لتحقيق مطلب المستخدم بأمان، لا تقليص صامت لنطاقه.

## تجربة الإثبات قبل اختيار التقنية

- شركة وفرع ومستخدمان وجهازان تجريبيان؛ لا بيانات حقيقية.
- نموذج مستند غير مالي لإثبات التخزين وإعادة التشغيل؛ ثم طلب قبض وحجز بمرجع الترحيل الحالي، لا نواة مالية ثانية.
- معرف عملية ثابت، وإعادة الإرسال 3 مرات ينتج عنها أثر واحد.
- قطع الاتصال قبل وأثناء وبعد إرسال الطلب؛ استعادة الجهاز لا تفقد الطلب ولا تعرض فشلًا كنجاح.
- مرفق محفوظ محليًا ومعرّف checksum ورفع قابل للاستئناف دون فقد الرابط.
- تعديلان لنفس السجل: مراجعة إصدار؛ لا سحق تعديل بصمت.
- آخر مكان: أحد الطلبين يقبل والآخر ينتظر، أو كلاهما ضمن حصص غير متداخلة.
- التحقق من سحب صلاحية/انتهاء تفويض وتغيير فترة مالية عند عودة الاتصال.
- ترقيم مؤقت أو نطاق معتمد يحفظ الرقم المطبوع وتاريخه وسجل الأرقام غير المستخدمة.
- مقارنة مستقلة بين عدد العمليات والمبالغ والقيود والتخصيص والسعة قبل/بعد المزامنة.
- استعادة نسخة تشمل الطابور غير المرسل والمرفقات والسياسات، وليس قاعدة الخادم وحدها.

## ما لا يفعله هذا المستند

لا ينشئ وحدة `sync-engine` خارج خريطة الملكية المعتمدة، ولا يضع الديون في localStorage، ولا يغير قيود أو مخزون شركة. أي مالك جديد للمزامنة أو HR يضاف أولًا لخريطة المعمارية بنطاق واضح بعد تجربة الإثبات. لا يُدّعى نجاح تجربة لم تُشغّل.
